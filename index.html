Gym tracker · iOS and Android

Log the lift. Count the calories. See who's at the gym.

Atlas started as a Java Android app for a UBC Okanagan HCI course. It is now two native apps, SwiftUI on iOS and Kotlin with Jetpack Compose on Android, with the logic held to one shared spec. The phone on this page is a working sketch of both: switch platform, tap around, log a lift.

One spec, two native apps

Same rules on both phones, because the same file says so.

spec/fixtures.json holds sample data and test cases for the leaderboard order, the calorie maths and the check-in board. The Swift tests (SharedSpecTests.swift) and the Kotlin tests (SharedSpecTest.kt) both read it. To change behaviour you add a case there first, then make both suites pass.

Not run yet

This page runs the same fixtures.json against a small JavaScript port of the rules (assets/logic.js). The real Swift and Kotlin suites run in CI, not here.     Build and run

    Two toolchains, one repo.

    iOS

    Xcode 16 or newer. The logic tests run on macOS without a simulator.

    cd ios/AtlasCore && swift test
open ios/Atlas.xcodeproj

    Android

    JDK 17 or newer and Android SDK 35.

    cd android
./gradlew :core:test
./gradlew :app:installDebug
